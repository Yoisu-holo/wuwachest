# 鸣潮桌宠 · 宝箱助手

一个独立的 Windows 小工具，用来照看《鸣潮》桌宠 **Wuwa Tappo**：自动领取宝箱、实时显示字符数、记录领取历史，顺带把联机房间和字符统计也管起来。

**不注入、不修改桌宠本体**。它通过 WebView2 的调试端口读取页面状态、触发页面上的按钮，读不到时退回 Windows UI Automation，两条路都不碰桌宠的安装文件。

> 第三方工具，与库洛游戏、Wuwa Tappo 官方无关。使用前请先看文末的免责声明。

---

## 功能

**自动领取**
读取页面上的宝箱倒计时，到期后等 2 秒再领；两个槽位都会处理，领完 30 秒复查是否还有。字符数不足 1000 时不会乱点，日志会写「余额不够，按钮被页面隐藏」。

**实时状态**
不是轮询：通过页面内的推送机制，字符数、宝箱、倒计时一变，面板立刻更新。连接断了会自动重连。

**内部通道加字符**
调用桌宠自带的隐藏动作（官方那个 +10000 按钮同一条通道），三档：+1000 / +5000 / +10000，瞬间到账、不动鼠标。

**领取记录与奖励图**
每次领取写一行日志：时间、字符数变化、消耗、奖励名。奖励图不是截屏，而是从页面里取奖励原图再合成一张卡片——所以领取时桌宠不会闪。

**联机房间**
实时读取当前房间号和房主；自动记录进过的房间（最近 30 个）；支持一键重连，失败会写明原因（格式不对、等不到输入框、按钮灰着、等待超时）。

**统计图表**
按小时记录累计字符数，可在「逐小时（最近 24 小时）」和「逐天（最近 14 天）」之间切换；柱状是新增，折线是累计。

**其他**
托盘常驻、单实例、开机自启、领取成功通知、自定义背景图（整窗一张图）、日志按天切割。

## 界面

五个标签页：

| 标签页 | 内容 |
| --- | --- |
| 状态 | 当前字符数、宝箱状态、状态更新、下次检测、今日领取数、最近日志；右下角显示版本号 |
| 领取记录 | 每天明细（时间、字符数变化、消耗、奖励、截图），可预览、导出 CSV |
| 设置 | 重试间隔、通知、截图、奖励图模式、优先 CDP、自动监控、开机自启、背景图 |
| 工具 | 联机房间（当前房间 + 历史 + 重连）、内部通道加字符 |
| 统计 | 字符数曲线（逐小时 / 逐天切换） |

## 环境要求

Windows 10 / 11，.NET Framework 4.7 或更高（Win10 1803 之后系统自带），以及已经安装并登录的 Wuwa Tappo 桌宠。

## 快速开始

把 `WuwaChest.exe` 放到一个固定目录，双击运行，面板会出现在屏幕中间。

第一次启动可能会弹一次 UAC：工具需要写一条 WebView2 的调试端口策略，必要时会重启一次桌宠（约 4 秒），这是正常的。

之后在「设置」里确认「优先用 CDP 读页面」是勾上的，回到「状态」点「开始监控」即可。关窗口会收进托盘，右键托盘图标才能退出。

命令行也支持一些常用参数：直接运行打开面板，`--tray` 只驻留托盘，`--history` / `--settings` / `--tools` / `--stats` 直接切到对应页，`--probe` 打印识别到的界面元素用于排障，`--once` 检测一次，`--boost 1000` 加字符，`--sync-export` / `--sync-import` 同步数据，`--set-background` 设置背景图。

## 配置文件

程序第一次运行会在 exe 同目录生成 `config.json`，改完在「设置」页点「保存并应用」。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `notReadyRetryMinutes` | 5 | 桌宠没开 / 读不到界面时的重试间隔（分钟） |
| `heartbeatSeconds` | 5 | 没有推送时的兜底刷新间隔（秒） |
| `verifyDelayMs` | 1200 | 点击后等多久复查状态（毫秒） |
| `notifyOnClaim` | true | 领取成功后弹托盘通知 |
| `autoStartMonitor` | true | 程序启动后自动开始监控 |
| `logRetentionDays` | 30 | 日志保留天数 |
| `rewardScreenshots` | true | 是否记录奖励图 |
| `rewardShotMode` | dom | `dom` 从页面取图合成（不闪屏）；`screen` 用 CDP 截图（会闪一下） |
| `rewardShotDelayMs` | 900 | 点击后等多久生成奖励图（毫秒） |
| `backgroundImage` | 空 | 面板背景图（相对 exe 目录或绝对路径） |
| `backgroundDim` | 45 | 背景图压暗程度 0–90 |
| `cdpEnabled` | true | 优先用 CDP |
| `cdpPort` | 9333 | 调试端口 |
| `cdpAutoEnable` | true | 启动时自动检查并写入调试策略 |
| `cdpAutoRestartPet` | true | 写入策略后自动重启桌宠让它生效 |
| `cdpDisableOnExit` | true | 退出时撤销「本次自己写的」策略 |

两个固定值不需要配置：领取一次消耗 1000 字符；没有 CDP 时的兜底检测间隔 30 分钟。

## 生成的文件

都在 exe 同目录：日志在 `logs` 目录（每天一个文件，奖励图在 `logs/rewards`），房间历史在 `rooms.txt`，字符数统计在 `stats.txt`，配置是 `config.json`。这些都不会进仓库。

## 常见问题

**面板显示「读不到桌宠界面」**：桌宠没启动，或者它以管理员权限运行而本工具没有，两者权限要一致。

**日志写「余额不够 1000，按钮被页面隐藏」**：字符数不足时页面根本不画宝箱按钮，攒够就会自己出现。

**奖励图带游戏背景**：说明走了屏幕裁剪，通常是 CDP 没通。检查设置里的端口和注册表策略。

**重连提示「需要桌宠面板」**：重连要用面板上的输入框，先手动点开一次桌宠的「设置」再重连。

**点击没反应**：确认桌宠窗口不是最小化；桌宠以管理员运行时，本工具也要管理员。
